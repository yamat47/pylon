The top of every page: the site's name at the start, its navigation at the end, and a rule under both.

`name` links to `href`, the top page. `description` is one line under the name in the muted ink. `nav` is a short list of links, shown as a `LinkList`; leave it out and the header has no navigation. Set `heading` on the top page only: the name is that page's title, so it becomes the page's `h1`. Every other page has a title of its own in its content.

The header is as wide as the page (`width-page`) whatever the content under it, so the name stays in one place from page to page.

- Do: keep `nav` to a few short words; it wraps under the name on a phone.
- Don't: put a logo, a search field or a button in it. The name is text and the header holds links only.
